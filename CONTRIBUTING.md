# Contributing

Pr's from anyone are welcome. This repo is meant to facilitate learning to students
who wish to learn more about coding. The intention of this project is to allow
people to explore what they are interested in.

## Steps

1. Get Informed, join the discord!
2. Find something to work on
    - ask around on discord for inspiration
    - look at currently opened issues in GitHub
    - write an RFC and pave your own path!
3. Start Coding
    - I recommend not using AI (see AI Policy below)
    - Ask for help from community members when you need help
4. Submit a PR
    - Message the code owner for a review

## AI Policy (from `@matchewf11`)

I believe that projects outside of school/work are essential for improving in
your skills. I find that AI helps me avoid thinking hard about a problem.
You can use AI when you get a job, slow down and learn! I am generally OK
with using it for inspiration or searching things up. However, I find that
allowing it to type code for me leads to my eyes glossing over.

My ask is that you write **ALL** of your code and docs by hand.
